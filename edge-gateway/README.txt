========================================================
 OnlineSCADA Edge Gateway — Quick Start Guide
========================================================

HOW TO CONNECT YOUR FACTORY PLCs:

STEP 1: Download config.json
----------------------------
- Login to your account at https://app.onlinescada.in
- Go to "Edge Gateways" in the sidebar menu
- Click "Download config.json"
- Move the downloaded config.json into THIS folder.

STEP 2: Start the Gateway
-------------------------
- Double-click "Start-Gateway.bat" to start.
- OR double-click "Run-In-Background.vbs" to run silently.

STEP 3: (Optional) Auto-Start on Reboot
---------------------------------------
- Double-click "Enable-AutoStart.bat" once.
- The gateway will now automatically run every time the PC powers on!
